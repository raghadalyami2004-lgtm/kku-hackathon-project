# What it does

Vision 2030 Sector Explorer helps students explore seven Saudi career sectors, read detailed sector information, and take a 10-question quiz to find their strongest match. It includes English/Arabic support, light/dark themes, a results radar chart, course recommendations, sharing, and a retake option.

# Who it is for

Students and early-career explorers who want a friendly introduction to Vision 2030 opportunities in Medicine, Nursing, Engineering, Tourism, Media, Cybersecurity, and Artificial Intelligence.

# Needs

Open it with an internet connection the first time so Google Fonts and the Chart.js 4.4.0 CDN can load. No account, installation, database, or personal information is needed.

# How to run it

Double-click `index.html` to open the app in a modern web browser. Use the Day/Night and EN/AR buttons in the header, explore any sector card, then take the quiz.

# Try it with the sample data

The quiz contains built-in made-up examples and keeps answers only in the current browser session. Use **Retake quiz** to clear the result and start again.

The opening animation includes a **Skip animation** button so every feature can be reached in under one minute.
